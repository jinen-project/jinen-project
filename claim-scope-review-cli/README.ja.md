# Claim Scope Review CLI

AIが「修正は安全で、本番投入できます」と答えたとき、そのまま報告や共有に使ってよいか迷うことがあります。この小さなローカルツールは、確認記録に足りない要素を見えるようにします。

最初は `example.review.json` をコピーし、実際に行ったテストと共有しようとしている主張に書き換えてください。実行すると、直接観測したこと、根拠の状態、まだ言えないこと、次に確かめる一点が記録されているかを確認します。

`READY_FOR_HUMAN_DECISION` は「人が判断するための記録項目がそろった」という意味です。主張の真偽や、その結果が目的に対して十分かどうかを自動で決めるものではありません。十分性は、依頼者など責任を持つ人が、合意した受入基準に照らして決めます。テキストを外部へ送信せず、アカウントやサービスにも接続しません。

## 最小の使い方

1. `example.review.json` を別名でコピーします。
2. これから共有するAI支援の結果について、実際に観測したことと主張を書きます。
3. 実行します。`HOLD` なら、表示された項目を埋めてから共有します。

```sh
node claim-scope-review.mjs example.review.json
```

## これは何を確認するか

- 共有したい主張
- 実際に起きたことと条件
- 根拠の状態
- 根拠からは言えないこと
- 次に確かめると結論が変わりうる一点

英語版の [README.md](README.md) と意味・根拠の範囲・非主張は同じです。
