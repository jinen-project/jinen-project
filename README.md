# Jinen Project

Runnable local software and public evidence for reliable AI-assisted workflows.

## Start here

1. [Reliable AI Workflow Demo](https://github.com/jinen-project/reliable-ai-workflow-demo) — a runnable local demo of approval boundaries, read-only tools, external readback, failure recovery, restart-safe execution, and audit timelines.
2. [Agent Action Preflight](https://github.com/jinen-project/agent-action-preflight-v1) — a local MCP action boundary that checks a concrete tool action before it executes.
3. [Evidence Packet](https://github.com/jinen-project/evidence-packet-v1) — a local evidence map that connects claims to supplied source passages and unresolved items.
4. [Share Preflight](https://github.com/jinen-project/share-preflight) — configurable local checks before material is shared with an external AI tool or service.
5. [Reversibility Review](https://github.com/jinen-project/reversibility-review-v1) — a local file-level review of what changed, what can be restored, and what remains afterward.

These are reference implementations and bounded local demonstrations. They are not production-ready systems, compliance certification, or guarantees for every workflow.

## What the projects have in common

- preserve source and provenance
- keep claims separate from verified results
- make authority and approval boundaries explicit
- verify external actions with readback
- preserve failure and unresolved states
- support restart-safe re-entry and regenerable views
