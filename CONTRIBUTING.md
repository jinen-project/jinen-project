# Contributing a useful observation

This is a small public collection of runnable specimens and field notes. The most useful contributions are concrete observations that help distinguish a local result from a broader claim.

## Open an issue when you have

- a result from running a specimen;
- an edge case or counterexample;
- a question about the stated scope; or
- a small improvement that would make a specimen easier to inspect.

Do not include credentials, private inputs, personal data, confidential code, or other material that should not be public.

## A useful issue has four parts

1. **What you tried** — the specimen, version or commit, and relevant conditions.
2. **What you observed** — what happened, as concretely as possible.
3. **What you expected** — what you thought would happen and why.
4. **What this may show** — a question, boundary, or limitation worth checking.

An issue records an observation. It does not create a commitment to support a workflow, implement a feature, merge a change, or make a broader claim.
